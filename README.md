# 골키퍼 키우기 3D

축구를 하는 게임이 아니라 골키퍼가 되는 게임. 슛 하나가 끝날 때까지 결과가 몇 번이나 뒤집힌다. 흙바닥 동네 운동장에서 시작해 훈련하고, 장비를 사고, 팔로워를 모은다.

플레이: https://lilmgenius.github.io/gtg-demo/

위키: https://lilmgenius.github.io/gtg-demo/web/wiki/site/ (게임 안 위키 패널과 같은 글이다)

## 로컬에서 돌리기

Node 22 이상. 서버 없이 정적 파일만 있으면 된다.

```
npm install
npm run serve
```

브라우저에서 http://127.0.0.1:10310/web/index.html 을 연다. 가로 화면이 기본이고 탭이 좌우, 홀드가 깊이를 정한다. 조작 전체는 위키의 조작 페이지에 있다.

## v1.0까지 거리

2026-09-24, v0.8.0(ea755a2) 기준 **10점 만점에 4.6점**. v1.0은 Play Store와 App Store 양쪽 승인이다. 지금 빌드는 잘 굴러가는 v0.8이고, 출시판은 아직 아니다.

| 항목 | 비중 | 점수 | 측정 |
| --- | ---: | ---: | --- |
| 엔지니어링 무결성 | 20% | 8 | 느린 게이트 100개 중 100개 통과. 태그 9개와 매니페스트, 라이브 빌드가 모두 0.8.0으로 일치. 출시 준비표에서 측정한 36행 중 32행 초록, 4행 빨강(그중 결정론 3행) |
| 코어 루프와 밸런스 | 20% | 7.5 | 밸런스 판정 55행 중 통과 49, 수용 1, 근거 부족 4, 실패 0. 남은 1행은 의도한 체험이라 사람이 판정해야 하고 아직 측정하지 않음 |
| 콘텐츠 범위 | 25% | 4 | 버전 사다리에서 실제로 만들어진 것은 v0.4 단계까지. 중거리 슛, 코너킥 헤딩, 프리킥, 풋살, 11대11은 아직 없음 |
| 기기와 성능, 접근성 | 15% | 3 | HITL을 뺀 준비표 80행 중 측정한 것은 36행. 프레임, Web Vitals, 30분 연속 플레이, 실기기 가독성은 미측정 |
| 시장 검증 | 20% | 0 | 외부 플레이어 0명, 텔레메트리 코드 없음, 스토어 제출 없음. D1과 D7 리텐션은 잴 수단부터 없음 |

올릴 순서는 이렇다. 먼저 결정론 빨강 셋(초기 로딩 용량, 가장 큰 에셋, 확률 검색)을 닫는다. 다음으로 외부인 다섯 명이 첫 판을 끝까지 하는지 보고, 텔레메트리를 붙여 리텐션을 잰다. 콘텐츠 사다리를 v0.9까지 채운 다음 스토어 심사에 넣는다. 시장 검증이 0점인 동안에는 나머지를 다 채워도 8점을 넘기 어렵다.
