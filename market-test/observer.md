# 관찰자 한 장 대본

상태: DRAFT. 파운더가 모집을 승인한 뒤 사용한다. 참여자는 게임을 처음 보는 외부인이고 개발자·내부 QA 표본과 섞지 않는다. 이름 대신 기록지의 익명 ID를 쓴다. 음성·화면 녹화는 별도 동의가 있을 때만 하고 기본은 시간과 행동 메모다.

<!-- 다섯 명과 사후 질문 셋은 P24b 요청이 정한 관찰 범위다. -->
준비: [기록지](observation.csv)의 다섯 행에 기기·브라우저·빌드·관찰 날짜와 시간대를 채운다. 새 게임 저장으로 시작하되 D1 관찰 때는 같은 기기·브라우저·저장소를 유지한다. 링크는 https://lilmgenius.github.io/gtg-demo/web/index.html?src=market-test 이다. 관찰 중 채널 영상이나 조작 설명을 먼저 보여 주지 않는다.

시작할 때 그대로 읽는다: “이 게임을 평소 웹에서 발견했을 때처럼 이용해 주세요. 그만하고 싶으면 언제든 그만해도 됩니다. 이용 방법은 제가 설명하지 않겠습니다. 말하고 싶은 것이 있으면 자유롭게 말씀해 주세요.”

시간 순서로 관찰하고 해석과 행동을 다른 칸에 쓴다.

| 순간 | 적을 것 |
| --- | --- |
| 링크를 열 때 | 실제 열린 시각, 화면이 뜨지 않거나 로드를 포기했는지, 게임 진입 시각 |
| 첫 플레이 가능 | 첫 공을 맞이할 수 있는 시각, 첫 조작과 망설임, 화면에서 스스로 읽은 단서 |
| 첫 접촉 | 키커가 공을 차는 첫 접촉 시각, 그 전후 이동과 반응, 결과 원인을 스스로 말했는지; 세이브 성공과 혼동하지 않음 |
| 첫 세트 끝 | 결과를 본 시각, 훈련·성장·재화를 자발적으로 확인했는지, 이해가 안 간 표정이나 말 |
| 다음 세트 | 시작 시각, 계속 조작했는지·그냥 열린 채였는지·봇인지, 그만둔 이유를 먼저 유도하지 않음 |
| 종료 | 자발적 종료 시각, 활성 손/봇/무입력 시간과 탭 숨김 시간, 기술 중단 여부 |

도움 요청에는 “평소라면 어떻게 하실 것 같나요?”만 말한다. 버튼 위치, 다음 목표, 훈련의 이점, 두 번째 판 목표를 알려 주지 않는다. 기술 오류로 중단하면 오류와 시각을 적고 성공이나 재미 실패로 바꾸지 않는다. 진행을 도왔다면 도움 칸에 그대로 적어 비코칭 표본에서 제외한다. 종료 시점을 강요하지 않고 중단된 관찰은 검열 표본으로 표시한다.

끝난 뒤 질문은 이 순서의 셋뿐이다. 답을 요약할 때 개인정보는 빼고 원뜻을 유지한다.

- “방금 무엇을 하려고 했고 어떤 일이 일어났나요?”
- “계속하거나 그만하기로 한 순간에는 어떤 생각이 들었나요?”
- “이 게임을 다시 열 상황이 있다면 어떤 상황일까요? 없다면 없다고 말씀해 주세요.”

D1을 재기 위해 다음 날 다시 하라는 알림이나 과제를 주지 않는다. 관찰자가 다시 하라고 요청했다면 요청 복귀로 따로 적는다. 거부·중단도 그대로 기록한다. 분석은 [보고 틀](report.md)에서 한다.
