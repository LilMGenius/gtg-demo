# 시장 시험 결과 보고 틀

상태: 미측정. 복사본과 원자료는 비공개 시험 폴더에 둔다. DRAFT 준비표를 실측 결과로 제출하지 않는다.

## 모집단과 원자료

실행 순으로 채운다: 배포 build_id=___ / 게시 채널·글 주소=___ / 모집·게시 승인=___ / 수집기 승인·수신 검증=___ / 시작과 종료 시각·시간대=___ / D1 관측 마감=___ / 관찰 CSV=___ / 원본 봉투 내보내기·해시=___ / 거부·수집 장애·삭제·도움 받은 표본=___ / 내부 QA·영상 캡처 제외 규칙=___.

관찰 다섯 명과 온라인 코호트는 합치지 않는다. 온라인은 install_id를 사용하고 event_id 중복을 제거한다. 동일 설치의 최초 first_playable로 유입 채널을 고정한다. 다른 기기와 저장소 초기화는 같은 사람이어도 다른 설치다. 최초 기록 이전의 이력과 누락은 알 수 없다. build_id별 표를 먼저 내고 빌드가 바뀐 복귀는 따로 표시한다. source가 direct면 채널을 추정해 채우지 않는다.

달력 D1은 local_day를 문자열 순서나 문자열 더하기로 비교하지 않고 연·월·일로 파싱해 다음 날짜를 구한다. 해당 다음 날짜가 끝나지 않은 설치는 미성숙으로 분모에서 빼고 수를 적는다. 경과 D1은 최초 occurred_at 이후 24시간 이상 48시간 미만의 플레이를 별도 표로 내며 그 창이 끝난 설치만 분모다. 정확 날짜와 그 이후 어느 날이든 돌아온 롤링 리텐션도 분리한다. 현지 날짜에는 시간대 오프셋이 없으므로 여행·시간대 변경 표본은 달력 판정의 한계로 적는다.

세션 길이: 관찰에서는 첫 플레이부터 자발적 종료까지와 활성 시간(탭 숨김 제외)을 각각 평균낸다. 중단 관찰은 검열로 표시하고 완결 표본과 섞지 않는다. 온라인은 session_id별 마지막 이벤트 시각에서 first_playable 시각을 뺀 하한만 낸다. heartbeat·종료·가시성 이벤트가 없어 이 하한으로 평균 세션 목표 달성/미달을 확정하지 않는다. 닫힌 탭의 전송 누락도 기록한다.

손/봇: 전체 set_complete에서 mode=hand와 mode=bot의 비중을 계산하고 혼합 세션 수를 병기한다. botRan이 있는 세트는 bot으로 기록되므로 순수 봇 시간 비율이라고 부르지 않는다. first_contact는 세션 최초 사건이므로 전체 슛 비율 분모로 쓰지 않는다. 관찰지의 손/봇/무입력 시간은 따로 집계한다. training_spent와 error, idle_accrual은 부록에서 흐름·수집 이상을 확인하는 자료다.
