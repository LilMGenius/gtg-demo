# 게임플레이 클립

상태: DRAFT. 실제 플레이 화면을 담는 무음 클립이며 신규 방문자의 성공률이나 외부인의 재미 증거가 아니다. 자막으로 미출시 콘텐츠나 실제 판매 기능을 약속하지 않는다.

<!-- 길이는 요청의 30~45초 안에서 36초를 택했다. 1280×720은 기존 tools/record.mjs의 가로 캡처 크기를 재사용한다. -->
목표는 36초, 1280×720 가로, 별도 파일 크기 상한 없음이다. 음원 권리·기기 루프백에 의존하지 않는 무음 DRAFT다. 캡처는 기존 녹화기의 고정 seed와 기존 veteran 프리셋을 썼다. 신규 온보딩을 건너뛴 도달 가능한 상태이며 새 방문자의 첫 화면이라고 소개하지 않는다. 게임 시계 가속과 연출 합성은 하지 않는다.

실행 순서의 샷 표다. 각 구간은 타이머 목표이고 실제 타임스탬프는 beats.json을 따른다.

<!-- 0~4, 4~28, 28~36초는 타이틀·플레이·성장 순으로 총 36초를 채우는 편집 배분이다. -->
| 구간 | 장면 | 입력과 확인 |
| --- | --- | --- |
| 0~4초 | 타이틀과 경기장 | 게임 이름을 읽을 시간을 두고 시작 |
| 4~28초 | 좌우 이동, 킥과 다이빙, 결과 자막 | 실제 화살표 입력으로 이동. 성공 장면을 보장하거나 결과를 주입하지 않음 |
| 28~36초 | 훈련장 확인, 경기장 복귀 | 도달 가능한 프리셋의 훈련 화면을 보여 주고 닫음. 새로운 모드 해금인 것처럼 보이지 않게 함 |

재사용 순서: [기존 녹화기](../tools/record.mjs)의 Playwright 실행 파일·seed·화면 크기와 [텔레메트리 계기](../tools/telemetry-gate.mjs)의 준비 완료 대기를 사용한다. demo-video의 CDP screencast 프레임과 타임스탬프 concat 방식을 써서 단 한 번 MP4로 인코딩한다. autoplay-qa의 고정 입력·별도 증거 원칙을 적용하되 이 게임의 턴 계약은 ALIGN의 지시대로 기존 GTG 계기를 따른다. 빌드 코드는 변경하지 않는다.

재현 명령과 캡처 소스, 도구 버전은 '.omo/evidence/p24b/capture-source.txt'와 'capture.json'에 있다. 로컬 서버 HTTP 성공, 브라우저 락 획득, 느린 쓸기 미실행을 확인한 뒤 캡처한다. 오류가 있으면 사용하지 않는다. 'ffprobe'의 영상 길이·해상도·프레임 수, 서로 다른 장면의 JPEG 직접 열람으로 확인한다. 최종 파일은 '.omo/evidence/p24b/gameplay.mp4', 장면 기록은 'beats.json', 점검 이미지는 같은 폴더의 JPEG다. 추적하거나 게시하지 않는다.
