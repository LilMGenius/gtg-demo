# 채널별 게시 초안

상태: 전부 DRAFT, 미게시. 채널은 텔레메트리 허용 목록 중 P24b가 지정한 채널의 알파벳순이다. 한국어와 영어 중 대상 공간의 언어 하나를 택한다. 일반 커뮤니티는 해당 공간이 허용하는 피드백 글에만 쓰고 CrazyGames와 Poki는 개발자 제출·테스트 요청 문구로 쓴다. 포털에 이미 올라갔다거나 채택됐다고 쓰지 않는다. 게임 UI는 한국어다.

[공개 주소의 출처](../README.md)는 루트 배포를 가리키지만 [루트 이동 페이지](../index.html)는 쿼리를 보존하지 않는다. 아래 링크는 같은 배포의 실제 게임 페이지에 src를 붙인다. [텔레메트리](../web/src/telemetry.mjs)가 src 또는 utm_source를 읽는다. 짧은 링크나 추적 리다이렉트를 새로 만들지 않는다. 공개 글을 읽은 코호트와 설명 없이 관찰한 외부인은 다른 모집단으로 집계한다.
