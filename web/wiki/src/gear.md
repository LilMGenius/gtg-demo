헤어와 수염은 별도 선반이다. 키퍼는 면도한 얼굴로 시작하고 수염을 선택해 착용한다. 등급을 사면 그 등급의 색 변형도 함께 열리며 변형 교체는 무료다. 착용한 수염은 키퍼마다 저장된다. 수염 색은 헤어 염색과 별개다.

헤어, 수염, 타투의 소문 확산은 합산하되 외형 효과의 기존 상한을 넘지 않는다. 키커의 수염은 선수 고유 외모다.


효과 이름은 판정 단계 순으로 읽는다. 확률의 변화는 퍼센트포인트, 첫발 지연은 시간, 행인 수는 인원, 팔로워 배율은 비율이다.

| 이름 | 뜻 |
| --- | --- |
| 장갑 벗겨짐 | 장갑이 벗겨지는 사고 |
| 흘림 | 손에서 흘리는 사고 |
| 첫발 지연 | 첫 발이 뜨는 데 걸리는 시간 |
| 강슛 밀림 | 정면 강슛에 같이 밀려 들어가는 사고 |
| 착지 실수 | 착지에 실패하는 사고 |
| 그물 흡수 | 그물이 공을 먼저 먹는 확률 |
| 행인 등장 | 눈에 띄는 행인이 지나갈 확률 |
| 행인 수 | 동네에 서 있는 행인 수 |
| 팔로워 배율 | 소문이 퍼지는 배율 |

헤어·수염·타투는 한 번 산 등급을 다시 장착해도 비용이 들지 않는다. 현재 착용한 등급은 착용, 보유한 다른 등급은 장착으로 표시된다. 보유 기록은 키퍼마다 저장하며 무료 면도로 돌아가도 산 수염은 남는다. 무료 면도는 색 변형이 없으며 시착 중이던 다른 수염의 색도 이어받지 않는다. 능력치 장비는 기존 상위 등급 구매 규칙을 따른다.

일부 최고 등급은 가격과 구매 조건을 함께 만족해야 살 수 있다. 자물쇠를 누르면 훈련, 경기 또는 아웃문그램으로 이동한다. 진행도는 저장된 현재 능력치, 레벨, 상대 전적의 세이브 합계, 팔로워에서 다시 계산하며 지출액은 조건이 아니다. 시착 묶음 구매와 캐시 결제도 같은 조건을 따른다. 아래 등급에는 이 조건이 없으므로 성장 경로는 열려 있다. 문턱은 수동 반응과 균등 훈련으로 가격을 모으는 시점을 기준으로 둔 HOTL 시험값이다.
